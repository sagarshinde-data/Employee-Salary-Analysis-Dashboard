# Employee-Salary-Analysis-Dashboard
Employee salary analysis project using Excel, Pivot Tables, Pivot Charts, KPIs and Slicers.

##Project Overview
This project analyzes employee salary data using Microsoft Excel. The dashboard provides insights into employee distribution, department-wise salaries, deductions, cities, and experience.

## Project Objectives
- Analyze employee salary data.
- Compare salaries across departments.
- Analyze employee distribution by gender and city.
- Understand salary deductions and net salary.
- Analyze average net salary based on experience.
- Build an interactive Excel dashboard.

## Dataset
The dataset contains 100 employee records, including:
- Employee ID and Name
- Gender
- Department and Designation
- Joining Date and Employment Type
- City and Experience
- Basic Salary, HRA, DA, Bonus, and Other Allowance
- PF, Tax, Other Deduction, and Net Salary

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas and Functions
- Slicers
- KPI Cards

## Key Features
- Department-wise Employee Count
- Department-wise Gross Salary Analysis
- Department-wise Net Salary Analysis
- Department-wise Average Salary
- Gender Distribution
- City-wise Employee Count
- City-wise Net Salary
- Experience-wise Average Net Salary
- Interactive Dashboard with Slicers

##  Key Learnings
- Data cleaning and preparation
- Data analysis using Pivot Tables
